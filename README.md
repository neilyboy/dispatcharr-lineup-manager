# Lineup Manager for Dispatcharr

A [Dispatcharr](https://github.com/Dispatcharr/Dispatcharr) plugin that turns several IPTV providers into
**one clean guide** and lets you run **logins for friends and family** from a single page.

| | |
|---|---|
| **One guide from every provider** | The same channel from different providers becomes one channel, with every provider's stream attached as failover, best stream limit first. |
| **Provider-agnostic** | Rules match provider *group names* (`US \| Sports`, `UK \| Sky Sports`...), not providers. Add or drop a provider in Dispatcharr and the next rebuild sorts it the same way. |
| **Keeps what you want** | Choose countries to keep (default US + UK). Foreign-language groups are left out; 4K, sports event slots and replays get their own groups. |
| **Nothing is lost** | *What's left out* lists every provider group not in the guide with stream counts. Paste a name into *Add back* and it becomes its own guide group. |
| **Event slots stay** | "NBA 12: NO EVENT" slots are kept, so they're there when a game fills them later in the day. |
| **Your own groups are safe** | Only the lineup's own groups are rebuilt. Groups you made by hand (cameras, local streams) are not touched. |
| **Members** | A table of name, username, streams, expiry and notes. *Save members* creates each member's Dispatcharr login (also works as an Xtream Codes login), turns members off when they expire, and *Renew* extends them by N months. |
| **Setup cards** | The server address, username and password to send each member. Works in any Xtream Codes / M3U player. |
| **Scheduled** | Rebuilds the lineup and checks expiries every N hours (default 2). |
| **Backup** | *Export settings* saves the lineup and members table (no passwords) to the plugin's data folder; Dispatcharr's own backups hold the logins. |

## Install

1. Download `lineup_manager.zip` from [Releases](../../releases), or build it with `scripts/build-zip.sh`.
2. Dispatcharr → **Plugins** → **Import** → choose the zip, then enable **Lineup Manager**.
3. Back up first (Dispatcharr → Settings → Backups). *Build lineup* replaces the channels in the lineup's own groups.

## Use

1. **Preview lineup** shows what each guide group would get. It changes nothing.
2. **Build lineup** builds it. **Turn on schedule** keeps it fresh.
3. **What's left out** lists everything else. Copy group names into **Add back**, save, and build again.
4. Add rows to **Members**, save settings, then **Save members**. **Setup cards** gives you what to send each person.
5. To renew, type `alice, bob` (or `all`) into **Renew** and press **Renew**.

### Members outside your home

Members connect to your Dispatcharr directly, so they need a way in. A reverse proxy with HTTPS on your own
domain (Caddy, Nginx Proxy Manager, Traefik) in front of Dispatcharr's port 9191 is the usual setup; put that
address in **Server address members use**. Each member's streams count against your providers' stream limits.

### Custom lineup

Leave **Lineup groups** blank to use the bundled [lineup.example.json](lineup_manager/lineup.example.json), or paste your own:

```json
{
  "countries": "US|USA|UK|GB",
  "skip_groups": "low ?bw|\\btest\\b",
  "groups": [
    {"name": "Sports", "start": 100, "sources": ["^(US|USA)\\s*\\|\\s*Sports\\b"]},
    {"name": "UK Sports", "start": 3000, "any_country": true, "sources": ["^(UK|GB)\\s*[|:].*(sky sports|tnt|dazn)"]},
    {"name": "NFL", "start": 4000, "merge": false, "sources": ["\\bnfl\\b"]}
  ]
}
```

| Key | Meaning |
|---|---|
| `name` | Guide group to build. |
| `start` | First channel number. |
| `sources` | Regexes matched against provider group names. A provider group goes to the first guide group that matches. |
| `merge` | `false` keeps every stream as its own channel (event slots, cameras). Default merges duplicates. |
| `include` / `exclude` | Regexes on channel names. |
| `any_country` | Ignore the countries filter for this group. |
| `skip_groups` | Provider groups this guide group should not take. |
| `min_providers` | Only keep channels offered by at least this many providers. |

## Privacy

Member passwords are generated by the plugin and stored only on the member's Dispatcharr user, never in plugin
settings or logs. The plugin never edits admins or users it didn't create.
